# GEO and AI discovery for Finow

The objective is to make verified Finow information easy for search engines and AI systems to parse, attribute and quote.

## Entity clarity

- clear organization description
- consistent Finow naming
- verified URLs and public profiles
- explicit relationship between Finow, its services and verticals
- current partner/provider claims only

## Answerability

Important pages should include concise answer-first passages for real user questions, followed by evidence/context.

Examples:

- فاینو چیست؟
- پرداخت اعتباری خدمات زیبایی چگونه کار می‌کند؟
- دندان‌پزشکی اقساطی چگونه پرداخت می‌شود؟
- پذیرنده چگونه در فاینو فعال می‌شود؟

## Evidence

Prefer:

- first-party product documentation
- current dated terms
- primary research/data when available
- authoritative external sources for health/finance facts

## Technical discovery

- crawlable HTML
- valid canonical/indexing
- useful structured data
- accurate updated dates
- consistent factual passages
- accessible robots policy consistent with business policy
- optional `llms.txt` as a discovery aid, never as a ranking/citation guarantee

## Audit outputs

Test whether major AI/search experiences represent Finow accurately when tools allow live checking. Record exact query, date, observed result and confidence.
