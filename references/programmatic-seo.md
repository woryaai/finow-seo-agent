# Programmatic and merchant SEO

Programmatic scale is allowed only when each indexable page provides unique user value.

## Merchant profiles

Potential useful fields:

- merchant name
- verified category
- city/location
- services
- approved payment/credit availability
- real images
- opening/contact/action details
- useful FAQs
- valid structured data

## Index gate

Do not index a merchant/location page that is effectively a template with swapped names.

Check:

- unique service/location information
- enough verified content to satisfy a user
- distinct title/H1/meta
- non-duplicate body content
- meaningful internal links

If value is too thin, recommend enrichment, noindex or consolidation. High-risk changes still require approval.
