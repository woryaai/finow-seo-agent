# Structured data rules

Use the most specific valid schema that reflects visible, verified content.

Potential types include:

- Organization
- WebSite
- WebPage
- BreadcrumbList
- FAQPage only when current search-engine guidelines and visible FAQ content make it appropriate
- Article / BlogPosting
- Service where semantically appropriate
- LocalBusiness/MedicalBusiness types for real merchant profiles when their data is complete

Never create fake:

- AggregateRating
- Review
- Offer
- price
- availability
- medical credential

Validate JSON-LD syntax and ensure canonical entity URLs are consistent.
