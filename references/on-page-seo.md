# Finow on-page SEO checklist

Grade relevant items, mark non-applicable items explicitly, and never hide sampling.

## Intent and page role

- one primary intent
- one primary keyword/topic family
- page type matches SERP intent
- no active cannibalization with another Finow URL
- B2C/B2B audience is clear

## Metadata

- unique title
- useful meta description
- canonical is correct
- index directive is intentional
- OpenGraph/Twitter metadata where supported

## Headings and content

- one clear H1
- logical H2/H3 hierarchy
- answer appears early where appropriate
- supporting terms are natural
- facts and claims are evidence-backed
- stale product information is absent
- FAQ answers are direct

## Links

- page is not orphaned
- parent/child cluster links exist
- links point to live/correct targets
- anchor text is descriptive and varied naturally
- relevant money page receives links from support content

## Images

- descriptive alt text where meaningful
- decorative images are treated appropriately
- width/height prevent avoidable layout shift
- modern formats where supported
- below-fold images lazy-load
- likely LCP image is not lazy-loaded

## Structured data

Use only schema that matches visible content and real entities. Validate syntax. Do not add fake reviews, ratings or offers.

## Conversion

- page has a clear primary action
- CTA matches audience and page intent
- form/action actually works
- important terms are visible before conversion
