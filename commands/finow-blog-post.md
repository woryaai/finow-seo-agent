# /finow-blog-post

## Purpose

Create one useful support article that satisfies real search intent, strengthens topical coverage and routes readers to the relevant Finow action/money page.

## Read first

- `AGENTS.md`
- `context/finow-brand.md`
- `context/finow-voice.md`
- `context/finow-compliance.md`
- `context/finow-product-facts.md` when commercial terms appear
- `references/iran-search.md`
- `references/on-page-seo.md`
- `references/content-quality.md`
- `references/persian-writing.md`
- `references/internal-linking.md`
- `references/geo-ai.md`
- `keyword-map.md`
- `website-index.md`

## Step 1 - Choose the row

If a topic is provided, verify it is not already owned by another active URL.

If omitted, select the highest-priority unwritten blog/support row in `keyword-map.md`.

Never overwrite an existing article silently.

## Step 2 - Verify intent and evidence

Inspect the current SERP for the target query/topic.

Record:

- dominant intent
- top result formats
- recurring subquestions
- obvious content gaps
- authoritative sources needed

For finance/health facts, use primary/authoritative evidence. Do not use SEO competitor repetition as factual proof.

## Step 3 - Define the reader

Write one sentence internally describing:

- who searched
- what decision/problem they have
- what the article should help them do next

Do not mix B2C and B2B unless the query itself is mixed.

## Step 4 - Draft structure

Default shape:

1. direct answer / quick orientation
2. context and definitions
3. main explanation
4. comparison/table only when it genuinely clarifies
5. Finow-specific explanation using verified product facts
6. practical next step
7. FAQ
8. CTA/bridge to relevant money page

Avoid long generic intros and keyword filler.

## Step 5 - Voice

Apply Finow voice. There is no forced humor rule.

B2C: warm, calm, clear and reassuring.

B2B: professional and operationally useful.

## Step 6 - SEO/GEO

Implement or propose:

- title/meta variants
- clean heading hierarchy
- answer-first passage
- relevant internal links
- article/breadcrumb schema where appropriate
- FAQ only when useful and visible
- clear updated/reviewed date when commercial information can age

## Step 7 - Quality gate

Score against `references/content-quality.md`.

Below 9/10: fix before marking `Ready`.

Product facts unresolved: keep `Draft` even if writing quality is high.

## Step 8 - Register

Update:

- `keyword-map.md`
- `website-index.md`

Set status accurately: `Draft`, `Review` or `Ready`.

Do not publish. `/finow-publish` handles publication.
