# Start here

## Claude Code

1. Unzip/open this repository.
2. Open a terminal in the repository root.
3. Run `python scripts/validate_repo.py`.
4. Run `claude`.
5. Start with:

```text
/finow-audit https://finow.pro
```

For keyword planning:

```text
/finow-keyword-research b2c cross
```

## Codex

Open the repository as the working project. `AGENTS.md` provides the persistent operating contract.

Start with:

```text
Run /finow-audit https://finow.pro
```

If your Codex client reserves unknown slash syntax, use:

```text
Run the finow-audit command against https://finow.pro, following AGENTS.md and commands/finow-audit.md.
```

Update verified commercial facts in `context/finow-product-facts.md`. Values marked `REVERIFY` are intentionally blocked from being treated as publishable facts.
